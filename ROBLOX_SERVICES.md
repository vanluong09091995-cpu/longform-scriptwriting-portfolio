# Roblox Animation & UI Services

I provide scoped Roblox animation and UI implementation/QA work using Roblox Studio, Moon Animator, and supporting Blender workflows where useful. Current public samples are internal capability work, not paid-client case studies.

## Roblox Animation — launch test pricing

### Basic — $20
- One simple loop/action
- One R6, R15, or usable custom rig
- Up to 10 seconds
- 1 revision
- 3-day delivery class after scope is confirmed

### Standard — $60
- Up to 3 related movement/combat animations
- One rig
- Up to 30 seconds aggregate
- 2 revisions
- 5-day delivery class

### Premium — $120
- Up to 6 related animations **or** one complex boss/combat sequence
- One rig
- Up to 60 seconds aggregate
- 2 revisions
- 7-day delivery class

Base animation packages exclude major rig reconstruction, Lua gameplay scripting, hitboxes, VFX, cinematics, extra characters, and major weighting repair unless separately scoped.

## Roblox UI

Launch target packages:
- **Basic $25** — one-screen QA/fix plan
- **Standard $65** — one-screen implementation/repair
- **Premium $125** — multi-screen implementation/QA up to 3 screens, subject to source review

UI work can include responsive Roblox Studio layout checks for mobile/desktop where the supplied project supports it. Complex backend systems, datastore/economy logic, and unrelated game scripting are outside the base UI scope.

## What to send before ordering

For animation:
- Rig type: R6 / R15 / custom
- Exact animation list
- Approximate duration
- Root-motion or in-place preference
- Intended gameplay use
- Reference clips/images you are authorized to share
- Known rig/import issues
- Delivery format and deadline

For UI:
- Screenshot/Figma/reference
- Target devices
- Current place/project state
- Available scripts/assets
- Expected interactions
- Deadline

Do **not** send passwords or account credentials.

## Working principles

- Original implementation rather than frame-for-frame copying
- Scope confirmed before work starts
- Compatibility risks stated before delivery
- Internal proof is labeled internal
- No invented client history, reviews, player metrics, or performance claims

## Start an inquiry

Open a public GitHub issue using the **Roblox service inquiry** template. Use the issue only for non-confidential scope information. Do not post private game files, credentials, identity documents, or unreleased proprietary material publicly.
