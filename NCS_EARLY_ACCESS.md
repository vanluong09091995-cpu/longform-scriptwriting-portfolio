# Narrative Content Studio 0.9.0 — Early Access

**Platform:** Windows 10/11 x64

Narrative Content Studio is a local-first desktop workspace for planning and producing long-form stories while keeping canon, continuity, versions, and backups under control.

## Built for

- Feature films
- Series
- Long-form YouTube
- Audio stories / audio drama
- Novels / web novels
- Custom long-form narrative projects

## Core workflow

- Story Bible
- Structure planning
- Writer workspace
- Canon and continuity review
- Timeline
- Project-wide search
- Versions and snapshots
- Backup & restore
- Crash recovery and autosave
- EN/VI interface
- ChatGPT Bridge workflow

## Why local-first

Version 0.9.0 stores project data locally and does not include built-in telemetry submission or automatic project uploads.

You decide when content leaves your machine.
